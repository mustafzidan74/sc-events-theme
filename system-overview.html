مكونات النظام الأساسية

Event (الفعالية)

العنصر الرئيسي في النظام

  • عنوان ووصف
  • تاريخ البداية والنهاية
  • المكان (حضوري/أونلاين)
  • الصور والجاليري
  • إعدادات التسجيل
  • حالة النشر

Ticket (التذكرة)

أنواع التذاكر للفعالية

  • اسم التذكرة
  • السعر
  • الكمية المتاحة
  • تاريخ بداية/نهاية البيع
  • الحد الأقصى للشراء

Attendee (الحاضر)

المسجلين في الفعالية

  • البيانات الشخصية
  • كود التذكرة (QR)
  • حالة التسجيل
  • حالة الدفع
  • الحقول المخصصة

Speaker (المتحدث)

المتحدثين والمحاضرين

  • الاسم والصورة
  • المسمى الوظيفي
  • السيرة الذاتية
  • روابط السوشيال ميديا

Session (الجلسة)

جلسات داخل الفعالية

  • عنوان الجلسة
  • الوقت والمدة
  • القاعة/المكان
  • المتحدثين

Transaction (المعاملة)

سجل المدفوعات

  • المبلغ والعملة
  • بوابة الدفع
  • حالة الدفع
  • رقم المرجع

Check-in (تسجيل الحضور)

تسجيل الدخول والخروج

  • وقت الدخول
  • وقت الخروج
  • مسح QR Code
  • الموظف المسؤول

Certificate (الشهادة)

شهادات الحضور

  • قالب الشهادة
  • كود التحقق
  • تاريخ الإصدار
  • تحميل PDF

Coupon (كوبون الخصم)

أكواد الخصم

  • كود الخصم
  • نسبة/قيمة الخصم
  • تاريخ الصلاحية
  • حد الاستخدام

Sponsor (الراعي)

رعاة الفعالية

  • اسم الراعي
  • اللوجو
  • مستوى الرعاية
  • الموقع الإلكتروني

Exhibitor (العارض)

العارضين في المعرض

  • اسم الشركة
  • رقم البوث
  • وصف المنتجات
  • معلومات التواصل

الكيان (Entity) العلاقة مرتبط بـ نوع العلاقة ملاحظات
Event → Tickets One to Many كل فعالية لها أنواع تذاكر متعددة
Event → Attendees One to Many كل فعالية لها حضور متعددين
Event ↔ Speakers Many to Many متحدث يمكن أن يشارك في عدة فعاليات
Event → Sessions One to Many فعالية كبيرة = عدة جلسات
Session ↔ Speakers Many to Many جلسة يمكن أن يكون لها عدة متحدثين
Attendee → Ticket Many to One كل حاضر مسجل بنوع تذكرة معين
Attendee → Transaction One to Many يمكن أن يكون له عدة معاملات
Attendee → Check-ins One to Many تسجيل دخول/خروج متعدد
Attendee → Certificates One to Many شهادات متعددة لفعاليات مختلفة
Event ↔ Sponsors Many to Many راعي يمكن أن يرعى عدة فعاليات
Event → Coupons One to Many أكواد خصم خاصة بكل فعالية

أنواع الفعاليات المدعومة

مؤتمر / Conference

مؤتمرات كبيرة بعدة جلسات ومتحدثين

  • جلسات متعددة
  • متحدثين متعددين
  • رعاة
  • معرض مصاحب
ورشة عمل / Workshop

تدريب عملي تفاعلي

  • عدد محدود من المشاركين
  • شهادات حضور
  • مواد تدريبية
ويبينار / Webinar

فعالية أونلاين

  • بث مباشر
  • رابط الانضمام
  • تسجيل الجلسة
حفل / Gala

حفلات ومناسبات

  • تذاكر VIP
  • جدول الفقرات
معرض / Exhibition

معارض تجارية

  • عارضين متعددين
  • خريطة المعرض
  • بوثات
سباق / Race

فعاليات رياضية

  • فئات المشاركة
  • تسجيل الأوقات
  • الترتيب
